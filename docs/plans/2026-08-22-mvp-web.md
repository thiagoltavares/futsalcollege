# MVP Web — Plano de Implementação

> **Para quem executa:** use `superpowers:subagent-driven-development` (recomendado) ou `superpowers:executing-plans` para implementar tarefa a tarefa. Os passos usam caixa de seleção (`- [ ]`) para acompanhamento.

**Objetivo:** entregar a versão web do MVP — cadastro com consentimento do responsável, ficha do atleta com visibilidade por campo, laudo assinado em PDF e pagamento — sobre um monorepo que permita acrescentar o app mobile depois sem reescrever regra de negócio.

**Arquitetura:** monorepo Turborepo + pnpm com `apps/web` (Next.js 16) e pacotes compartilhados. Toda regra de domínio — política de visibilidade, máquina de estados do perfil, validação — vive em `packages/core`, TypeScript puro, sem React e sem DOM: é isso que o Expo vai reaproveitar. A visibilidade de campo é imposta pelo Postgres via Row Level Security e por separação física de tabelas, não por disciplina de quem escreve query.

**Stack:** Next.js 16 (App Router, Turbopack), React 19, Tailwind 4, Supabase (Postgres + Auth + Storage + RLS), Turborepo, pnpm, Vitest, Playwright, `@react-pdf/renderer`, Asaas (PIX) atrás de uma interface.

## Restrições globais

Valores tirados literalmente do pre-PRD (`docs/pre-prd.md`). Valem para todas as tarefas.

- **Criança não é vitrine.** Ficha esportiva é pública e indexável. Vídeo, nome completo, contato e cidade só para olheiro verificado. Bairro, endereço, escola, local e horário de treino **não existem como campo em lugar nenhum**.
- **Não se vende posição.** Nenhuma ordenação, filtro ou consulta pode ler o campo de plano. O olheiro nunca sabe quem paga.
- **Laudo publicado não se edita.** Correção gera nova versão com a anterior visível.
- **Contato é sempre mediado.** Nenhum adulto de fora recebe canal direto com o atleta.
- **Ranking de criança nunca é público.** Não existe lista dos melhores, nota comparativa nem percentil exposto.
- **Consentimento é sempre do responsável**, com documento, mesmo quando quem cadastra é o treinador. Perfil sem consentimento não renderiza em lugar nenhum.
- **Dado de saúde** (postural, composição corporal, lesão) nunca é público, nem para olheiro verificado. Consentimento próprio e destacado.
- **Faixa etária:** Sub-7 a Sub-20.
- **Idioma:** todo texto de interface e de banco em português do Brasil.
- **Preços são hipotéticos.** Nenhum valor entra hardcoded no código — sempre via tabela `produtos`.
- Node 24, pnpm 9+, Next 16, React 19, Tailwind 4.

## Estrutura de arquivos

```
futsalcollege/
├── apps/
│   └── web/                        Next.js — produto + /plan + /profissional/flavio
│       ├── src/app/...
│       └── package.json
├── packages/
│   ├── core/                       TS puro. Sem React, sem DOM. O Expo reusa isto.
│   │   ├── src/visibilidade.ts     Política de visibilidade por campo
│   │   ├── src/perfil.ts           Máquina de estados do perfil
│   │   ├── src/rubrica.ts          Tipos da rubrica versionada
│   │   └── src/esquemas.ts         Schemas Zod de validação
│   ├── db/                         Schema, migrations e tipos gerados
│   │   ├── supabase/migrations/
│   │   └── src/tipos.ts            Gerado por `supabase gen types`
│   ├── api/                        Cliente tipado sobre supabase-js
│   ├── pagamentos/                 Interface de pagamento + adaptador Asaas
│   └── config/                     tsconfig e eslint compartilhados
├── docs/
├── turbo.json
├── pnpm-workspace.yaml
└── package.json
```

**Por que a divisão é essa:** `core` não importa nada de plataforma, então roda igual em Next e em Expo. `api` depende de `supabase-js`, que também roda em React Native. `apps/web` é a única coisa que o app mobile não vai reaproveitar. Isso é o que justifica o monorepo agora, e não depois.

```ts
/**
 * Política de visibilidade por campo.
 *
 * Fonte única da verdade sobre quem enxerga o quê. O banco impõe isto por RLS
 * e por separação de tabelas; este módulo existe para que a regra seja legível,
 * testável e reaproveitável pelo app mobile.
 *
 * Campos que localizam a criança — bairro, endereço, escola, local e horário de
 * treino — não aparecem aqui porque não existem no sistema. Não se vaza uma
 * coluna que nunca foi criada.
 */

export type Contexto = "publico" | "verificado" | "responsavel" | "profissional";

/** `saude` é mais restrito que `verificado`: olheiro nunca vê. */
export type Sensibilidade = "publico" | "identificacao" | "saude";

export const CAMPOS_ATLETA = {
  apelido: "publico",
  categoria: "publico",
  posicao: "publico",
  pe_dominante: "publico",
  altura: "publico",
  peso: "publico",
  clube_atual: "publico",
  estado: "publico",

  nome_completo: "identificacao",
  data_nascimento: "identificacao",
  cidade: "identificacao",
  contato_responsavel: "identificacao",

  avaliacao_postural: "saude",
  massa_magra: "saude",
  historico_lesao: "saude",
} as const satisfies Record<string, Sensibilidade>;

export type CampoAtleta = keyof typeof CAMPOS_ATLETA;

const ACESSO: Record<Sensibilidade, readonly Contexto[]> = {
  publico: ["publico", "verificado", "responsavel", "profissional"],
  identificacao: ["verificado", "responsavel", "profissional"],
  saude: ["responsavel", "profissional"],
};

export function campoVisivel(campo: string, contexto: Contexto): boolean {
  const sensibilidade = (CAMPOS_ATLETA as Record<string, Sensibilidade>)[campo];
  if (!sensibilidade) return false;
  return ACESSO[sensibilidade].includes(contexto);
}

export function camposVisiveis(contexto: Contexto): CampoAtleta[] {
  return (Object.keys(CAMPOS_ATLETA) as CampoAtleta[]).filter((c) =>
    campoVisivel(c, contexto),
  );
}
```

```ts
/**
 * Ciclo de vida do perfil do atleta.
 *
 * O treinador pode cadastrar uma turma inteira de uma vez: os perfis nascem em
 * `aguardando_consentimento` e ficam invisíveis até o responsável assinar.
 * Consentimento revogado derruba para `suspenso`; `removido` é terminal.
 */

export const ESTADOS_PERFIL = [
  "rascunho",
  "aguardando_consentimento",
  "ativo",
  "suspenso",
  "removido",
] as const;

export type EstadoPerfil = (typeof ESTADOS_PERFIL)[number];

const TRANSICOES: Record<EstadoPerfil, readonly EstadoPerfil[]> = {
  rascunho: ["aguardando_consentimento", "removido"],
  aguardando_consentimento: ["ativo", "removido"],
  ativo: ["suspenso", "removido"],
  suspenso: ["ativo", "removido"],
  removido: [],
};

export function podeTransicionar(de: EstadoPerfil, para: EstadoPerfil): boolean {
  return TRANSICOES[de].includes(para);
}

/** Só `ativo` aparece em página, busca, feed ou qualquer outro lugar. */
export function perfilRenderiza(estado: EstadoPerfil): boolean {
  return estado === "ativo";
}
```

```sql
-- Separação física por sensibilidade. O que identifica ou é de saúde mora em
-- tabela própria, com RLS própria. O que localiza a criança — bairro, escola,
-- endereço, horário de treino — simplesmente não tem coluna.

create type estado_perfil as enum (
  'rascunho',
  'aguardando_consentimento',
  'ativo',
  'suspenso',
  'removido'
);

create table responsaveis (
  id uuid primary key references auth.users (id) on delete cascade,
  nome text not null,
  criado_em timestamptz not null default now()
);

create table atletas (
  id uuid primary key default gen_random_uuid(),
  responsavel_id uuid not null references responsaveis (id) on delete cascade,
  estado estado_perfil not null default 'rascunho',

  -- Só campo público. Ver packages/core/src/visibilidade.ts.
  apelido text not null,
  categoria text not null,
  posicao text,
  pe_dominante text,
  altura_cm integer,
  peso_kg numeric(5, 2),
  clube_atual text,
  estado_uf text,

  criado_em timestamptz not null default now(),
  atualizado_em timestamptz not null default now()
);

create table atleta_identificacao (
  atleta_id uuid primary key references atletas (id) on delete cascade,
  nome_completo text not null,
  data_nascimento date not null,
  cidade text,
  contato_responsavel text
);

create table atleta_saude (
  atleta_id uuid primary key references atletas (id) on delete cascade,
  avaliacao_postural jsonb,
  massa_magra_pct numeric(5, 2),
  historico_lesao text,
  atualizado_em timestamptz not null default now()
);

create index atletas_estado_idx on atletas (estado);
create index atletas_categoria_idx on atletas (categoria) where estado = 'ativo';
```

- [ ] **Passo 1: Escrever a migration de RLS**

`packages/db/supabase/migrations/0002_rls.sql`:

```sql
alter table responsaveis enable row level security;
alter table atletas enable row level security;
alter table atleta_identificacao enable row level security;
alter table atleta_saude enable row level security;

-- Ficha pública: qualquer um lê, mas só perfil ativo.
create policy atletas_leitura_publica on atletas
  for select
  using (estado = 'ativo');

-- O responsável enxerga e edita os próprios atletas em qualquer estado.
create policy atletas_do_responsavel on atletas
  for all
  using (responsavel_id = auth.uid())
  with check (responsavel_id = auth.uid());

create policy responsaveis_proprio on responsaveis
  for all
  using (id = auth.uid())
  with check (id = auth.uid());

-- Identificação: responsável dono, e olheiro verificado.
create policy identificacao_responsavel on atleta_identificacao
  for all
  using (
    exists (
      select 1 from atletas a
```

```sql
-- O treinador cadastra, mas quem consente é sempre o responsável. Um perfil só
-- chega a 'ativo' com consentimento vigente, e a checagem mora no banco: não
-- adianta uma tela esquecer de validar.

create table consentimentos (
  id uuid primary key default gen_random_uuid(),
  atleta_id uuid not null references atletas (id) on delete cascade,
  responsavel_id uuid not null references responsaveis (id) on delete cascade,
  documento_url text not null,
  versao_termo text not null,
  aceito_em timestamptz not null default now(),
  revogado_em timestamptz,
  ip inet,
  agente text
);

create index consentimentos_atleta_idx on consentimentos (atleta_id);

create or replace function consentimento_vigente(p_atleta uuid)
returns boolean
language sql
stable
as $$
  select exists (
    select 1 from consentimentos c
    where c.atleta_id = p_atleta and c.revogado_em is null
  );
$$;

create or replace function exigir_consentimento()
returns trigger
language plpgsql
as $$
begin
  if new.estado = 'ativo' and not consentimento_vigente(new.id) then
    raise exception 'perfil % não pode ficar ativo sem consentimento vigente', new.id
      using errcode = 'check_violation';
  end if;
  return new;
end;
$$;

create trigger atletas_exigir_consentimento
  before insert or update of estado on atletas
  for each row
  when (new.estado = 'ativo')
  execute function exigir_consentimento();

-- Revogar consentimento derruba o perfil na hora.
create or replace function derrubar_ao_revogar()
returns trigger
language plpgsql
as $$
begin
  if new.revogado_em is not null and old.revogado_em is null then
    update atletas set estado = 'suspenso' where id = new.atleta_id;
  end if;
  return new;
end;
$$;

create trigger consentimentos_derrubar
  after update of revogado_em on consentimentos
  for each row
  execute function derrubar_ao_revogar();

alter table consentimentos enable row level security;

create policy consentimentos_do_responsavel on consentimentos
  for all
  using (responsavel_id = auth.uid())
  with check (responsavel_id = auth.uid());
```

```ts
"use server";

import { esquemaAtleta } from "@futsalcollege/core";
import { redirect } from "next/navigation";
import { criarClienteServidor } from "@/lib/supabase/servidor";

export async function criarAtleta(_estadoAnterior: unknown, formulario: FormData) {
  const bruto = Object.fromEntries(formulario) as Record<string, string>;

  const analise = esquemaAtleta.safeParse({
    ...bruto,
    altura_cm: bruto.altura_cm ? Number(bruto.altura_cm) : undefined,
    peso_kg: bruto.peso_kg ? Number(bruto.peso_kg) : undefined,
  });

  if (!analise.success) {
    return { erro: analise.error.issues[0]?.message ?? "Dados inválidos" };
  }

  const supabase = await criarClienteServidor();
  const { data: sessao } = await supabase.auth.getUser();
  if (!sessao.user) redirect("/entrar");

  const d = analise.data;

  const { data: atleta, error } = await supabase
    .from("atletas")
    .insert({
      responsavel_id: sessao.user.id,
      apelido: d.apelido,
      categoria: d.categoria,
      posicao: d.posicao ?? null,
      pe_dominante: d.pe_dominante ?? null,
      altura_cm: d.altura_cm ?? null,
      peso_kg: d.peso_kg ?? null,
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { redirect } from "next/navigation";
import { VERSAO_TERMO } from "@/conteudo/termo-2026-08-v1";
import { criarClienteServidor } from "@/lib/supabase/servidor";

export async function assinarConsentimento(atletaId: string, formulario: FormData) {
  const documento = formulario.get("documento");
  if (!(documento instanceof File) || documento.size === 0) {
    return { erro: "Anexe um documento de identidade." };
  }
  if (documento.size > 8 * 1024 * 1024) {
    return { erro: "O arquivo precisa ter menos de 8 MB." };
  }

  const supabase = await criarClienteServidor();
  const { data: sessao } = await supabase.auth.getUser();
  if (!sessao.user) redirect("/entrar");

  const caminho = `${sessao.user.id}/${atletaId}-${Date.now()}`;
  const { error: erroEnvio } = await supabase.storage
    .from("termos")
    .upload(caminho, documento, { upsert: false });

  if (erroEnvio) return { erro: "Não consegui enviar o documento. Tente de novo." };

  const { error: erroConsentimento } = await supabase.from("consentimentos").insert({
    atleta_id: atletaId,
    responsavel_id: sessao.user.id,
    documento_url: `termos/${caminho}`,
    versao_termo: VERSAO_TERMO,
  });

  if (erroConsentimento) return { erro: "Não consegui registrar o consentimento." };

  // O gatilho do banco só deixa passar porque o consentimento acima já existe.
  const { error: erroAtivacao } = await supabase
    .from("atletas")
    .update({ estado: "ativo" })
    .eq("id", atletaId);

  if (erroAtivacao) return { erro: "Consentimento salvo, mas o perfil não ativou." };

  revalidatePath(`/atleta/${atletaId}`);
  redirect("/painel");
}

export async function revogarConsentimento(atletaId: string) {
  const supabase = await criarClienteServidor();

  // O gatilho derrubar_ao_revogar suspende o perfil sozinho.
  const { error } = await supabase
    .from("consentimentos")
    .update({ revogado_em: new Date().toISOString() })
    .eq("atleta_id", atletaId)
    .is("revogado_em", null);

  if (error) return { erro: "Não consegui revogar. Tente de novo." };

  revalidatePath(`/atleta/${atletaId}`);
  return { ok: true };
}
```

```ts
import type { Database } from "@futsalcollege/db";
import type { SupabaseClient } from "@supabase/supabase-js";

export type Supa = SupabaseClient<Database>;

/**
 * Colunas da ficha pública, escritas à mão de propósito: `select("*")` passaria
 * a vazar qualquer coluna nova sem ninguém perceber. O teste ao lado garante
 * que esta lista não sai da política de visibilidade.
 */
export const COLUNAS_FICHA_PUBLICA =
  "id, apelido, categoria, posicao, pe_dominante, altura_cm, peso_kg, clube_atual, estado_uf";

export async function buscarFichaPublica(supabase: Supa, id: string) {
  const { data, error } = await supabase
    .from("atletas")
    .select(COLUNAS_FICHA_PUBLICA)
    .eq("id", id)
    .eq("estado", "ativo")
    .maybeSingle();

  if (error) throw error;
  return data;
}

export async function listarAtletasDoResponsavel(supabase: Supa) {
  const { data, error } = await supabase
    .from("atletas")
    .select("id, apelido, categoria, estado")
    .order("criado_em", { ascending: false });

  if (error) throw error;
  return data ?? [];
}
```

```ts
import type { Cobranca, NovaCobranca, Pagamentos, StatusCobranca } from "./porta";

type Config = { chave: string; base: string; fetch?: typeof fetch };

type RespostaAsaas = {
  id: string;
  status: string;
  value: number;
  invoiceUrl?: string;
  pixCopiaECola?: string;
};

const STATUS: Record<string, StatusCobranca> = {
  PENDING: "pendente",
  AWAITING_RISK_ANALYSIS: "pendente",
  RECEIVED: "paga",
  CONFIRMED: "paga",
  OVERDUE: "expirada",
  REFUNDED: "cancelada",
  DELETED: "cancelada",
};

function traduzir(bruto: RespostaAsaas): Cobranca {
  return {
    id: bruto.id,
    status: STATUS[bruto.status] ?? "pendente",
    valorCentavos: Math.round(bruto.value * 100),
    urlFatura: bruto.invoiceUrl,
    pixCopiaECola: bruto.pixCopiaECola,
  };
}

export function criarAsaas(config: Config): Pagamentos {
  const buscar = config.fetch ?? fetch;

  async function chamar(caminho: string, init?: RequestInit) {
    const resposta = await buscar(`${config.base}${caminho}`, {
      ...init,
      headers: {
        "content-type": "application/json",
        access_token: config.chave,
        ...(init?.headers ?? {}),
      },
    });

    if (!resposta.ok) throw new Error(`Asaas respondeu ${resposta.status}`);
    return (await resposta.json()) as RespostaAsaas;
  }

  return {
    async criarCobranca(dados: NovaCobranca) {
      const bruto = await chamar("/v3/payments", {
        method: "POST",
        body: JSON.stringify({
          billingType: "PIX",
          value: dados.valorCentavos / 100,
          description: dados.descricao,
          externalReference: dados.referenciaExterna,
          dueDate: dados.vencimento,
        }),
      });
      return traduzir(bruto);
    },

    async lerCobranca(id: string) {
      return traduzir(await chamar(`/v3/payments/${id}`));
    },
  };
}
```

```ts
import { criarAsaas } from "@futsalcollege/pagamentos";
import { NextResponse } from "next/server";
import { criarClienteServidor } from "@/lib/supabase/servidor";

export const runtime = "nodejs";

export async function POST(requisicao: Request) {
  const supabase = await criarClienteServidor();
  const { data: sessao } = await supabase.auth.getUser();
  if (!sessao.user) return NextResponse.json({ erro: "não autenticado" }, { status: 401 });

  const corpo = (await requisicao.json()) as {
    produto: string;
    atletaId?: string;
    pagador: { nome: string; email: string; cpfCnpj: string };
  };

  const { data: produto } = await supabase
    .from("produtos")
    .select("chave, nome, valor_centavos")
    .eq("chave", corpo.produto)
    .eq("ativo", true)
    .maybeSingle();

  if (!produto) return NextResponse.json({ erro: "produto inexistente" }, { status: 404 });

  const { data: registro } = await supabase
    .from("cobrancas")
    .insert({
      produto_chave: produto.chave,
      responsavel_id: sessao.user.id,
      atleta_id: corpo.atletaId ?? null,
      valor_centavos: produto.valor_centavos,
    })
    .select("id")
    .single();

  const pagamentos = criarAsaas({
    chave: process.env.ASAAS_API_KEY!,
    base: process.env.ASAAS_BASE_URL!,
  });

  const vencimento = new Date(Date.now() + 3 * 24 * 60 * 60 * 1000)
    .toISOString()
    .slice(0, 10);

  const cobranca = await pagamentos.criarCobranca({
    referenciaExterna: registro!.id,
    valorCentavos: produto.valor_centavos,
    descricao: produto.nome,
    pagador: corpo.pagador,
    vencimento,
  });

  await supabase.from("cobrancas").update({ psp_id: cobranca.id }).eq("id", registro!.id);

  return NextResponse.json({
    id: registro!.id,
    urlFatura: cobranca.urlFatura,
    pixCopiaECola: cobranca.pixCopiaECola,
  });
```

- [ ] **Passo 2: Webhook**

`apps/web/src/app/api/webhook/asaas/route.ts`:

```ts
import { createClient } from "@supabase/supabase-js";
import type { Database } from "@futsalcollege/db";
import { NextResponse } from "next/server";

export const runtime = "nodejs";

/**
 * O webhook usa a chave de serviço porque não há sessão de usuário aqui — mas
 * só depois de conferir o token combinado com o PSP. Sem essa checagem, qualquer
 * um marcaria qualquer cobrança como paga.
 */
export async function POST(requisicao: Request) {
  if (requisicao.headers.get("asaas-access-token") !== process.env.ASAAS_WEBHOOK_TOKEN) {
    return NextResponse.json({ erro: "token inválido" }, { status: 401 });
  }

  const evento = (await requisicao.json()) as {
    event: string;
    payment: { id: string; status: string };
  };

  if (!["PAYMENT_RECEIVED", "PAYMENT_CONFIRMED"].includes(evento.event)) {
    return NextResponse.json({ ignorado: true });
  }

  const admin = createClient<Database>(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.SUPABASE_SERVICE_ROLE_KEY!,
    { auth: { persistSession: false } },
  );

  await admin
    .from("cobrancas")
    .update({ status: "paga", pago_em: new Date().toISOString() })
    .eq("psp_id", evento.payment.id);

  return NextResponse.json({ ok: true });
}
```
